Filosofía Open Source & Tecnología Libre

Defensor activo del software libre y la tecnología abierta como pilares de una educación tecnológica accesible, colaborativa y de calidad:

  • GitHub como aula colaborativa: uso de repositorios, pull requests y revisión de código como metodología pedagógica activa.
  • Linux en el aula: promoción de sistemas operativos libres (Ubuntu, Raspberry Pi OS) para entornos educativos sin costos de licencia.
  • GitHub Copilot & IA generativa: integración ética en la enseñanza de programación para acelerar el aprendizaje y fomentar el pensamiento crítico.
  • Contribución a proyectos abiertos: motivación a los estudiantes a colaborar en proyectos reales de la comunidad open source.
  • Herramientas libres en el stack educativo: VS Code, LibreOffice, GIMP, Blender, Arduino IDE, Jupyter Notebook como alternativas gratuitas y potentes.
  • Cultura DevOps básica: introducción a flujos de trabajo con Git, versionado de código y documentación técnica (Markdown, README).
